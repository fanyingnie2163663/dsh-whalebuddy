# 工作区 / 空白会话分配 · 设计

- 日期：2026-11-14
- 状态：**已批准**（2026-11-14；布局按老板要求改为侧栏内嵌，不另开画面）
- 相关：[2026-11-13-colleague-console-design.md](2026-11-13-colleague-console-design.md)

## 1 意图

控制台现在只能看和改记忆，不能"安排人"。老板要在这页上把一个工作区交给某个同事：点一下，就用她的预设在这个工作区开一个新会话；该工作区里已有可复用的空白会话时，直接指给她，第一条消息就带着她的记忆。

## 2 硬约束（查过宿主源码）

- **预设锁定**：`agentPresets.select()` 在会话已有轮次时抛 `agent-preset/locked`（"This session has already started"）。所以**已经开始的会话不能中途换人**。
- **可复用空白**：`uiWorkspace.startSession(workspaceId, { agentPreset })` 会复用该工作区里"未归档、未开始、未记录预设或正好是请求的预设"的第一个空白会话；没有就新建，并打开它（`connectWorkspace` + 导航）。
- **工作区列表**：宿主 `workspaceRegistry.list()` 返回带 `id`、`path`、`sessionIds` 的实体；路径就是工作目录。
- 以上都在本机 0.2.2-rc.3 的 `app.asar` 声明/实现里确认过。

## 3 目标 / 非目标

**目标**
1. 控制台左栏列出工作区（名字取目录名，路径作为提示）。
2. 每个工作区一行"用她开会话"：把该工作区记进她的档案，然后用她的预设打开（复用空白或新建）。
3. 已绑定的工作区有可见标记；绑定可重复点击而不重复写。

**非目标**
- 不给已开始的会话换预设（宿主禁止）。
- 不做"从所有会话里挑一个指定"的列表：`startSession` 已按上面的规则复用空白，够用。
- 不做解绑、批量分配、跨同事转交。
- 不改工作区本身（不移动、不改名）。

## 4 数据与接口

### 4.1 档案

`profile.md` 的 `- 工作区：` 行保存逗号分隔的绝对路径（与 `store.create` 已有的格式一致）。分配是**追加 + 去重**，不重排、不动其它行；没有这一行时补在末尾。

### 4.2 宿主

| 方法/路径 | 变更 |
|---|---|
| GET `/api/whalebuddy/state` | 响应新增 `workspaces: [{id, title, path}]`；`colleague` 新增 `bound: string[]`（从档案解析） |
| POST `/api/whalebuddy/assign` | `{slug, workspaceId}`：校验 slug 是已存在同事、workspaceId 在 registry 里；用 **registry 里的 path**（不信客户端传的路径）追加进档案，返回 `{saved, bound, preview}` |
| 无 | 不新增会话创建路由：会话由客户端 `uiWorkspace.startSession` 创建/复用并导航 |

路由沿用现有围栏：connection/loopback、方法、slug 存在性；工作区未知回 404。

### 4.3 客户端

`apply(ctx)` 里取 `ctx.get('uiWorkspace')` 的 `startSession`，注入页面；页面左栏在同事列表下加「工作区」段：

```
工作区
- 未命名项目   已绑 · 开
- 小肥鱼日记        开
```

点「开」：`POST /api/whalebuddy/assign` → 成功后 `startSession(workspaceId, { agentPreset: 'whalebuddy:<slug>' })`。分配失败不打开会话；`uiWorkspace` 缺失时提示"当前界面不支持从面板开会话"，不改档案。

## 5 验收

- [ ] 面板列出两个工作区，名字正确。
- [ ] 选「逆戟」→ 点「未命名项目」的「开」→ 档案 `工作区：` 出现该路径，界面切到一个预设为 `whalebuddy:逆戟` 的会话。
- [ ] 该工作区已有她的空白会话时复用，不产生第二个会话。
- [ ] 该工作区已有别的同事的空白会话时新建，不抢占。
- [ ] 未知 workspaceId / 未知 slug / 非 POST 分别 404 / 404 / 405；非本机 403。
- [ ] `npm run check` 全绿。

## 7 布局修订（2026-11-14）

工作区不另开画面，直接放进 Whalebuddy 侧栏，并且**跟着当前选中的同事**：

```
同事
 ● 逆戟  视频
     未命名项目        开
     小肥鱼日记        开
     ＋ 指定工作区
 ● 一角  美术
 ＋ 新建同事
```

- 已绑的工作区直接列在她的名字下，点「开」= 分配（若未绑）+ 开新会话；
- 未绑的收进「＋ 指定工作区」，展开后选一个，同样是分配 + 开；
- 其它同事不显示这一段，侧栏始终只有一列。

## 6 风险

- `uiWorkspace.startSession` 是客户端服务；个别旧壳没有它。缺失时只提示，不静默失败。
- 绑定只增不减，档案行会慢慢变长；解绑留到下一版。
- 会话开始后仍不能换人；这条要在面板上写清楚，避免"点了没反应"的误解。
