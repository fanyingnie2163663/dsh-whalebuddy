# 同事（Whalebuddy）设计文档

- 日期：2026-11-09
- 状态：待你点头
- 工作名：`dsh-whalebuddy`（Whalebuddy），界面里叫「同事」
- 命名说明：界面里对人的称呼是「同事」——不用"员工/下属"，因为那偏雇佣与从属；你要的是"长期共事、各司其职、又懂你"。产品与包名叫 **Whalebuddy**：鲸群（pod）里的 buddy，接 DSH 的鲸；PodBuddy 与播客 App 重名，故不用。

## 1. 意图

现在的 DSH 里，"懂你"这件事困在会话里。换一个工作区、开一个新会话，她对这个项目、对你这个人的理解就清零，你只能把资料再贴一遍、再让她读一遍。

这个项目要把那部分"懂"从会话里拿出来，做成独立、持续存在的东西：**一个同事**。她有档案（她是谁）、有阅历（她记得什么）、有工具箱（她会什么），开新会话时自己把自己带回来；不同同事各自积累、互不串味；她主动到什么程度、你们怎么相处，由你调。

一句话：**把预设从"配置模板"变成"岗位"，把岗位变成"人"。**

## 2. 目标

1. 开新会话时，同事自动带着理解上场，不需要重贴资料、重新解释你。
2. 每个同事有独立、可读、可改、可迁移的记忆与档案。
3. 记忆自动积累（收工提炼），不靠你手写。
4. 同事在侧边栏有位置，你能一眼看出谁在、谁在忙、谁最近干了什么。
5. 主动性分档可调（L1/L2/L3），用户自选，同事级可覆盖。
6. 基于 DSH 预设：预设是岗位说明书，同事是上岗的人；说明书换代时同事可选跟不跟。

## 3. 非目标

- 不做微调训练、不做模型层改造。
- 不做云端同步、多设备、多用户。
- 不做语音、IM 通道、角色立绘（以后可接）。
- 不做同事市场 / 分享。
- 不接管 DSH 的会话与工作区管理，只在其上加一层。

## 4. 反目标（做到了也算失败）

- 记忆是黑箱：你看见不、改不了"她为什么知道这个"。
- 记忆自己悄悄改写：今天记的规则明天被"优化"没了，且无痕迹。
- 同事之间互相读私有记忆。
- 主动性变成骚扰。
- 为这个去 patch DSH 本体，一升级就崩。
- 同事只是换了皮的预设：开新会话还是什么都不记得。

## 5. 约束

- **跑在 DSH 上**：Host 插件 + Client UI，只用公开服务，不改本体。
- **预设**：`ctx.agentPresets`——`register(PresetDefinition)` 可运行时注册，`select` / `recompose` 可切换，会话头记录 `agentPreset`。
- **注入**：`ctx.systemPrompt.section / context / variable`，每次模型请求前装配。
- **会话 / 工作区**：`ctx.agents`、`ctx.workspaceRegistry`、`ctx.workingDirectory`、`ctx.sessionQuery`（历史会话读取）。
- **存储**：同事数据落成 Markdown / JSON，人类可读；索引可重建。
- 单机、单用户、中文界面优先。

## 6. 方案选择

| 方案 | 做法 | 取舍 |
|---|---|---|
| **A. 文件 + 注入**（选中） | 每人一个文件夹：档案、默契、知识、日志；开场注入摘要，收工提炼写回 | 独立、可读、可改、可迁移；天然多同事隔离。代价：注入是摘要，细节靠召回 |
| B. 记忆引擎 | SQLite + 向量/混合检索，每轮按需召回 | 召回强；但黑箱、难改、难迁移，"默契"这类软知识检索不准 |
| C. 会话继承 | 续上次会话或常驻读旧会话 | 零损耗；但上下文越滚越大、越贵，跨场景串味，做不了多同事 |

选 A。B 作为召回兜底（P4），C 不做。

**主动性**做成档位而非一次性选择：L1 随叫随到 / L2 会来找你（默认）/ L3 自己找活。

## 7. 设计

### 7.1 概念

- **预设（岗位）**：她是谁、用什么模型、带哪些 skill 和权限。可复用、可升级。
- **同事（人）**：预设的一个实例，有自己的名字、档案、记忆、工具箱，独立演化。
- **公共档案**：关于"你"的硬规矩（称呼、底线、通用偏好），一份，全员读。
- **私房默契**：这个同事和你之间攒下的相处方式——语气、习惯、你俩的暗号、你纠正过她的点。
- **收工**：一次共事结束时的整理，把值得留下的写回记忆。
- **待确认**：提炼出来但拿不准、或与旧记忆冲突的条目，等你看一眼。

### 7.2 数据布局

```
~/.dsh/whalebuddy/
├── _shared/
│   └── user.md              # 关于你：称呼、底线、硬规矩（全员可读，改动需你确认）
├── index.json               # 同事列表、预设映射、全局设置
└── <slug>/                  # 一个同事
    ├── profile.md           # 档案：名字、岗位、脾气、档位、工作区绑定
    ├── memory/
    │   ├── hot.md           # 热记忆：每次开场必注入（≤ 800 字）
    │   ├── rapport.md       # 私房默契：语气、习惯、被纠正过的点、定过的规矩
    │   ├── knowledge.md     # 知识：项目事实、决定、坑（每条带 workspace 归属）
    │   ├── tasks.json       # 待办：她答应你的、你交办的（结构化，驱动提醒）
    │   ├── log/
    │   │   └── 2026-11-09.md
    │   ├── changelog.md     # 记忆的每次变更（谁、何时、为什么）
    │   └── rejected.md      # 你否掉的条目：提炼时必须读，防止写回
    ├── skills/              # 她自己长出来的 skill
    ├── pending/             # 待确认条目（一条一个 json）
    └── state.json           # 预设 id/版本、活跃时间、统计、档位快照
```

**条目约定**：`rapport.md` / `knowledge.md` 每条以 `- [id] (workspace:* 或 <id>) 内容` 开头；`tasks.json` 每条有 `id / 来源会话 / 截止 / 状态 / 已提醒`；任何改动追加到 `changelog.md`。

原则：**记忆是文件，不是数据库里的行**。你能 `git diff`、能手改、能整包拷走；索引只是缓存，随时可重建。

### 7.3 同事的一生

1. **入职**：向导创建——名字、岗位（选一个预设）、三句话性格、自主性档位、绑定工作区（可多选，也可不绑）。生成 `profile.md` 与一份同事预设。
2. **上岗**：开她的会话，预设挂载，开场注入把记忆带进上下文。
3. **共事**：正常对话。她说"记住这个"就当场写；其余先留在会话里。
4. **收工**：会话结束 / 你说"收工" / 到点批处理，三者之一，跑提炼。
5. **复盘**：进 `pending/` 的在详情页给你过目；你确认后并入记忆。
6. **升级**：岗位预设换代时提示"要不要跟"；跟 = 换工具与默认行为，**记忆不动**。
7. **退休**：归档，目录留着，不再出现在列表。

**默认名池**（创建时可挑一个，也可自己起）——名字自带脾气，选名字就是选性格：

| 名字 | 脾气 |
|---|---|
| 小白 Beluga | 温和、耐心，适合日常与陪伴 |
| 逆戟 Orca | 锋利、直接、话少，适合写码与挑错 |
| 座头 Humpback | 爱唱爱总结，适合复盘与讲故事 |
| 一角 Narwhal | 钻研、刨根问底，适合研究与查资料 |
| 蓝鲸 Blue | 大、稳、扛重活 |

### 7.4 开场注入

每次请求装配时，按优先级拼一段"她是谁 + 她记得什么"：

| 顺序 | 内容 | 上限 |
|---|---|---|
| 1 | 身份：名字、岗位、你们的关系、语气 | 200 字 |
| 2 | 私房默契：语气、习惯、纠错、规矩 | 500 字 |
| 3 | 待办：她答应你的事、你交办的事 | 200 字 |
| 4 | 近况：最近 3 天日志 + 当前工作区相关事实（标 `workspace:*` 的也带） | 300 字 |
| 5 | 公共档案：user.md 摘要 | 150 字 |

总预算 **约 1200 tokens**，超了从后往前砍；被砍的不丢，落在召回里。

注入带一句隐式约定："这些是你的记忆，不是用户刚说的话；不确定就先问，别假装记得没记过的事。"

### 7.5 收工提炼

- **输入**：本次会话增量 + 现有记忆摘要 + `rejected.md`（必须读）+ `changelog.md` 最近条目。
- **输出**（严格 JSON schema）：
  - `report` 这次做了什么（进日志）
  - `promises` 她答应你的、你交办的（进 tasks.json）
  - `corrections` 你纠正她的点（进默契，最高优先级）
  - `preferences` 你的偏好与说话方式（进默契；与公共档案冲突的进待确认）
  - `facts` 项目事实、决定（进知识，带 workspace）
  - `questions` 拿不准、想问你的（进待确认）
- **合并**：只增不删；冲突不覆盖，两条都留、进待确认；同一事实反复出现才算稳定；命中 `rejected.md` 的直接丢弃。
- **成本**：少于 6 个有效轮次不跑；低档位攒到每天一次批处理；"记住这个"立即写。
- **失败**：出错不写任何东西，保留原始会话，下次重试；连续两次失败降级为只存日志并提示。
- **压缩**：`hot.md` 满了，旧条目降级到 `rapport.md` / `knowledge.md` 或合并成摘要；**规则与纠错永不自动降级**；所有压缩记 `changelog.md`。

### 7.6 召回

- 热记忆永远在场。
- `colleague_recall(query)`：先关键词/路径匹配，P4 再上本地向量；结果带来源文件与行号，方便核对"她凭什么这么说"。
- `colleague_remember(text, section)`：显式写入，可见、可撤回。
- `colleague_status()`：看自己的档位与待办。

### 7.7 在场（界面）

侧边栏常驻一块「同事」区，每个人的状态在这里：

```
同事
├ 小码    写码的      ● 在      昨天 23:40 改完爬虫登录
├ 阿望    日常/想法   ○ 离线    3 天前
└ ＋ 新同事
```

- **列表**：名字、岗位、状态（在 / 离线 / 在忙）、最近活动；点开直接进她的会话或详情。
- **详情页**：档案（可改）、记忆浏览（按文件与条目）、待办、待确认队列、变更历史、工具箱、档位、工作区绑定。
- **创建**：四步向导，两分钟建完。

### 7.8 自主性分档

| 档位 | 行为 | 护栏 |
|---|---|---|
| **L1 随叫随到** | 只在会话里工作；收工时提炼 | 无后台任务；不主动发消息 |
| **L2 会来找你**（默认） | 收工整理；到点提醒答应的事；有进展主动说一声；每日小结 | 安静时段；**全局每天主动消息 ≤ 2（单人 ≤ 1）**，超了顺延不丢；每条可撤回；月预算上限 |
| **L3 自己找活** | 后台常驻；从待办里自己挑活；可提方案等你点头 | 预算上限；工具白名单；外发动作必须插件级确认（本机审批已关，不能依赖 DSH 审批）；实验性，默认关 |

三层设置：全局默认 → 同事覆盖 → 单次会话临时；任何一档都能一键降到 L1。

**她来找你，落在哪**：她自己的会话里多一条消息 + 侧边栏头像亮起 / 状态变化；不弹窗、不打断你当前会话。需要更响可另开桌面通知开关。

### 7.9 预设绑定与升级

- 每个同事由插件在启动时用 `ctx.agentPresets.register()` **动态注册**一份 `whalebuddy:<slug>`，不写 `cordis.patch.yml`、不动 profile。
- `~/.dsh/whalebuddy/` 是唯一真相源；插件启动按 `index.json` 自愈补注册，整包拷走同事还在。
- 注册的预设 = 岗位模板的插件行 + 一条 `dsh-whalebuddy` 行（config 里带 slug），会话一开就知道是谁。
- 模板升级：检测到新版本 → 列表标"可升级" → 你点跟，重新注册；记忆目录原样不动。

### 7.10 入职迁移（暂缓）

老会话里已经攒了不少"懂"。技术上可以选工作区/会话，一次性提炼成档案草稿。

**按你的意思：暂时不做，也不拿你本地现有会话当试验田**。等同事从零开始跑稳（P3 之后）再回头看，到时另说范围。

### 7.11 共享与隔离（混着来）

- **公共档案 `_shared/user.md`**：只放硬规矩——称呼、底线、别反问、别废话、输出格式这类。全员读，改动由你确认；同事只能提议。
- **私房默契 `rapport.md`**：语气、习惯、你俩的暗号、你纠正过她的点。每个同事一份，互不可见，允许不一致（这就是"不同的人"）。
- 同事私有记忆默认互不可见；跨同事协作需显式授权，留记录。

### 7.12 并发

同一同事可同时开多个会话。提炼**按会话排队、串行写**，加文件锁；`hot.md` 合并冲突进待确认，不静默覆盖。临时档位以最晚一次会话设置为准，会话结束回落到同事档位。

## 8. 分期

| 期 | 内容 | 验收 |
|---|---|---|
| **P1 骨架** | 数据布局、动态注册同事预设、开场注入、侧栏列表与创建、切换、**最小收工**（日志 + 热记忆 + 待办写回） | 建同事 → 说三句话 → 关掉 → 明天新会话，她能接上，不需要重贴资料 |
| **P2 收工** | 完整提炼管线、待确认队列、公共档案、记忆浏览/编辑/变更历史 | 一次共事结束，日志与默契有更新；错的能改掉，且不再写回 |
| **P3 在场** | 侧栏状态、L2 调度、主动消息、提醒、桌面通知开关 | 她按点提醒你答应的事；一天 ≤ 2 条 |
| **P4 深水区** | L3、向量召回、skill 自演化、模板升级、迁移（另议） | L3 跑一周不越界；召回能答"三周前那个决定" |

## 9. 成功标准

1. 新会话第一句就能接上：抽查 10 次 ≥ 8 次不需要你再解释背景。
2. 记忆可信：30 秒内能找到"她为什么知道这个"，并能改掉。
3. 不烦人：L2 下日均主动消息 ≤ 2，每条都能关。
4. 可带走：整个 `~/.dsh/whalebuddy/` 拷到另一台机器，同事还在。

## 10. 风险

| 风险 | 应对 |
|---|---|
| 提炼写脏，越记越离谱 | 只增不删、冲突进待确认、拒绝清单、changelog、可 git 版本化、一键回滚 |
| token 成本 | 预算封顶、按增量提炼、低档位批处理 |
| 主动性变骚扰 | 全局硬上限、安静时段、一键静音 |
| 多同事串味 | 目录隔离 + 按同事注入 + 私有记忆不串 |
| 并发写冲突 | 串行队列 + 文件锁 + 冲突进待确认 |
| DSH 升级打断 | 只用公开服务，不 patch 本体；预设重注册而非硬改 |
| "假记得" | 注入时明确"不确定就问"；召回带来源 |

## 11. 留给构建者的

- 会话开始/结束的确切事件与 payload（`ctx.agents.announce` 附近），以及"会话空闲"判定。
- Client Slot 选点（侧边栏、详情页、创建向导）。
- 存储实现：直接文件 vs `ctx.storageDomain`；索引放哪。
- `PresetDefinition.plugins` 的模板来源：从岗位预设的 `readDocument` 复制，还是本插件自带一份可编辑模板。
- 提炼 prompt 与 JSON schema 的细节、失败重试策略。
- 向量召回选型（P4）。

## 12. 已拍板、你可以推翻

- 命名：界面叫「同事」，产品/包名 Whalebuddy（`dsh-whalebuddy`），数据目录 `~/.dsh/whalebuddy/`；理由：鲸群 pod + buddy，接 DSH 的鲸；PodBuddy 与播客 App 重名故不用。
- 记忆用文件而非数据库；注入预算 1200 tokens。
- 预设运行时注册，不写 profile。
- 默认档位 L2，L3 默认关闭；主动消息全局每天 ≤ 2。
- 公共档案只放硬规矩，相处方式归私人。
- P1 带最小收工；迁移暂缓。
- 改记忆 = 追加修订 + 作废旧条；压缩留痕，规则与纠错不自动降级。
