# 同事控制台 · 视觉落地

- 日期：2026-11-14
- 状态：**已实现**（2026-11-14，`dsh-whalebuddy/lib/client.js`）
- 决策：方案 **C** —— 结构照设计稿，颜色跟 DSH 主题，衬线只做标题，陶土色只做装饰
- 落地偏差：陶土左缘画在选中卡内（-1px）；窄屏列表是可横滑的头像条，「新建」吸右；向导标题固定「新同事」，步骤标题只在正文出现
- 设计来源：`designs/colleague-ui/project/`（8 张画板，本地目录，不进仓库）
- 相关：[2026-11-13-colleague-console-design.md](2026-11-13-colleague-console-design.md)（功能设计，仍然有效）

## 1 意图

功能已经能用了：三栏、七个文件、保存即回传注入预览。缺的是让人愿意每天打开的那层东西——设计稿里，同事是有脸、有状态、有痕迹的人，不是一张文件清单。

这一版把稿子的**信息结构和气质**落到 `lib/client.js`：不动宿主、不加依赖、不引入构建步骤。

## 2 目标 / 非目标 / 反目标

**目标**

1. 列表像「人」：头像字、衬线名字、岗位、最近活动。
2. 详情像「档案」：头像 + 名字 + 档位 / 工作区 / preset 徽标 + 五个标签页。
3. 记忆按文件分区读得下去，每条带来源（`memory/hot.md · 第 3 行`）。
4. 新建做成四步向导（名字 → 岗位 → 脾气 → 档位），选名字即定脾气。
5. 深浅色都像原生：不写死底色，跟随 DSH 主题。

**非目标**

- 不做「在岗 / 离线」的假状态：没有在场数据就不显示。
- 不做待确认队列、条目级记忆编辑（等 P2）。
- 不做路由或多页；仍是 `main` 槽位里的一个页面。
- 不改 `lib/host/panel-data.js` 与 `lib/host/routes.js`。

**反目标（做到也算失败）**

- 造数据：状态点、条数、来源行号必须能从现有文件算出来，算不出就不显示。
- 和外壳打架：深色主题里出现固定浅底、覆盖全局变量。
- 换了皮却丢了核心闭环：改一行 → 立刻看到注入。

## 3 约束

- 客户端是**单文件、无构建**的浏览器脚本（`__ModuleLoader__` + `React.createElement`），只能加纯函数和组件，不能 `import`。
- 面板在 DSH `main` 槽位里：高度由外壳给，宽度随侧栏和窗口变；没有自己的返回栏、标题栏、窗口边。
- 只能用 `state` 路由已经给的数据：`employees / selected / colleague.files / colleague.bound / colleague.preview / workspaces`。
- 写入仍走现有三条路由；白名单、64 KB 上限、本机守卫都不变。
- 渲染测试跑在裸 VM 的假 React 里，不能依赖 DOM API。

## 4 方案

| | 做法 | 取舍 |
|---|---|---|
| A | 整包照搬暖纸色，自带深浅两套 | 最像稿；但会成 DSH 里唯一一块别的皮肤，深色要自己接，维护双份色板 |
| B | 只借结构，颜色全用 `--dsw-*` | 和外壳最一致；暖感和纸的质感基本没了 |
| **C（选中）** | 结构 100% 照稿；底色 / 文字 / 边框用 DSH 变量；标题用衬线；陶土只做装饰 | 白天夜里都成立，和别的面板同族；代价是稿子的米色底不做 |

**陶土色的边界**：`#D97757` 只出现在 2px 选中下划线、选中卡左缘、未保存圆点、待办到期日，不承载正文。固定色配深色主题时，陶土上的白字对比度不够；主按钮保持 DSH 的 `button-primary-fill`，才不会和外壳主色打架。

## 5 设计

### 5.1 信息架构（单页，无路由）

```
┌ 同事（衬线） 3 位 · 最近更新 2 小时前        [注入预览] [+ 新同事] ┐
├──────────────┬───────────────────────────────────┬──────────────┤
│ 白  小白      │ (白) 小白  Beluga · 写码的          │ 她开场收到什么 │
│     写码的    │      ● 记忆更新于 2 小时前          │              │
│     ● 2 小时前 │      [L2 会来找你] [示例项目]  [whalebuddy:xiaobai] │
│ 逆  逆戟      │───────────────────────────────────│ ### 身份      │
│     挑错的    │ 档案 · 记忆 47 · 待办 2 · 花名册 · 变更 │ # 小白        │
│ + 新建        │                                   │ ...          │
└──────────────┴───────────────────────────────────┴──────────────┘
```

右栏在宽度 ≥ 1180px 时常驻；更窄时收成右侧抽屉，标题栏的「注入预览」开合。

### 5.2 视觉 token 映射

| 设计稿 | 实现 |
|---|---|
| 象牙底 `#FAF9F5` / 深色 `#13161D` | `--dsw-alias-bg-base` |
| 列表底板 `#F6F2E8`、卡片 `#FFFFFF` | 同底色 + `1px solid var(--dsw-alias-border-l1)`；卡片不加阴影 |
| 主文字 / 次文字 | `--dsw-alias-label-primary` / `-secondary` / `-tertiary` |
| 分隔线 / 输入框 | `--dsw-alias-border-l1` / `-l2` |
| 输入底 | `--dsw-specific-input-major` |
| 悬停底 | `--dsw-alias-interactive-bg-hover` |
| 陶土 `#D97757` | 常量 `--wb-clay`，仅装饰 |
| 衬线标题 | `"Noto Serif SC", "Source Han Serif SC", "Songti SC", Georgia, serif`，字重 600 |
| 主按钮 | `--dsw-alias-button-primary-fill` / `-hover`，文字 `--dsw-alias-label-primary-foreground` |
| 状态点 | 绿 `--dsw-alias-state-success-primary`，灰 `--dsw-alias-label-tertiary` |

头像底色用 `color-mix(in oklab, var(--dsw-alias-bg-base) 84%, #D97757)`：浅色下是沙色，深色下是暖灰，不用两套变量。

### 5.3 组件

| 组件 | 规格 |
|---|---|
| 列表项 | 56px 高；38px 圆形头像（名字首字，衬线 17px）；名字 15px/500；次行 12.5px「岗位 · 最近活动」；右侧活跃点 8px。选中态：卡片底 + 边框 + 左侧 2px 陶土线 |
| 档案头 | 56px 头像；名字衬线 28px；次行 13px；右侧徽标组（档位 / 第一个工作区 / preset id），多工作区显示「+N」 |
| 标签页 | 档案 / 记忆 / 待办 / 花名册 / 变更；40px 高；选中 2px 底边（陶土）；计数用 11.5px 次文字 |
| 记忆分区 | 三张卡：热记忆（限 800 字）/ 私房默契（只有你和她看得见）/ 知识（带工作区归属）。每条非空行一段，来源行 `memory/hot.md · 第 N 行`（等宽 11px）；空分区显示一句空状态 |
| 编辑态 | 卡片右上「编辑」→ 同卡内换成 textarea + 保存 / 取消；一次只开一个编辑器；草稿进现有 `drafts`，所以切同事的未保存提示自动生效 |
| 档案页 | 主动性卡（L1/L2/L3 + 一句行为说明 + 权重条）、工作区卡（已绑 + 开 / 指定）、档案原文编辑 |
| 待办页 | 圆形勾选；正文 + 到期日（陶土）；勾选即存；全部完成显示空状态 |
| 花名册页 | 共享文件，标注「全员可见」，编辑保存 |
| 变更页 | 只读；按 `- [YYYY-MM-DD HH:MM] 来源：内容` 解析成「时间 · 来源 · 内容」三列；解析不了的行原样显示 |
| 预览 | 标题「她开场收到什么」+ 字数；`pre` 等宽 11.5px；空态一句；保存后由 host 回传替换 |
| 新建向导 | 覆盖面板（不是整窗）的四步：名字（5 个人设卡 + 自定义输入）→ 岗位（5 个建议 + 自定义）→ 脾气（≤80 字）→ 档位（三卡带护栏说明）；右侧实时预览卡；Esc 关闭 |

人设与预填：

| 名字 | 拉丁 | 脾气（预填） | 建议岗位 |
|---|---|---|---|
| 小白 | Beluga | 温和、耐心，适合日常与陪伴 | 日常 |
| 逆戟 | Orca | 锋利、直接、话少，适合写码与挑错 | 写码 |
| 座头 | Humpback | 爱唱爱总结，适合复盘与讲故事 | 复盘 |
| 一角 | Narwhal | 钻研、刨根问底，适合研究与查资料 | 研究 |
| 蓝鲸 | Blue | 大、稳、扛重活，适合长线项目 | 重活 |

创建接口只收 `name / role / autonomy / temperament`，工作区在创建后从列表里绑——向导不假装能一步绑工作区。

### 5.4 响应式

- 用 `container-type: inline-size` 在面板根上做容器查询，断点看面板自身宽度，不看窗口。
- ≥ 1180px：264px 列表 + 主区 + 320px 预览。
- 820–1179px：240px 列表 + 主区；预览变抽屉（右侧 360px，带遮罩）。
- < 820px：列表收成顶部横向头像一个条（72px 高），主区占满；预览抽屉全宽。
- 兜底：容器查询不可用时用同样两条宽度的 `@media`。

### 5.5 数据映射（全部现成，不改接口）

| 界面元素 | 来源 |
|---|---|
| 名字 / 岗位 / 档位 / 最后更新 | `employees[]` 的 `name` `role` `autonomy` `updatedAt` |
| 头像字 | `name` 首字符（`Array.from` 取，兼容 emoji） |
| 活跃点 | `Date.now() - updatedAt`：< 24h 绿、< 7d 灰、更久更淡；tooltip「记忆最后更新：……」 |
| 徽标 | `autonomy`、`state.workspaces` 与 `colleague.bound` 对上的标题、`whalebuddy:<slug>` |
| 记忆条目与来源行 | `files.hot / rapport / knowledge` 按行切；行号 = 非空行在原文件中的行号 |
| 待办 | `files.tasks` 解析成数组 |
| 变更 | `files.changelog` 逐行解析 |
| 预览 | `colleague.preview` |
| 工作区 | `state.workspaces`（id / title / path）+ `colleague.bound`（path） |

### 5.6 深浅色

默认**深色**（2026-11-14 反馈：浅色太亮）；标题栏右侧一键切换，选择存在 `localStorage['whalebuddy.theme']`，不跟随外壳主题。

实现上不加第二套组件样式：`data-wb-theme="dark"` 只在面板根上覆盖同一组 `--dsw-*` 变量（底色、文字、边框、输入框、主按钮、状态色），组件仍只认变量。深色调色板取自设计稿的深色三张画板。

## 8 风险与留给实现者

1. **单文件变大**：约 900 → 1500 行。纯函数集中放顶部，按 `// --- 区块 ---` 分区，禁止引入依赖或 JSX。
2. **衬线字体**：Windows 上没有 `Noto Serif SC` 会落到 SimSun，大字号观感不同。先接受系统栈；字体子集打包要等有资产生成流程再说。
3. **容器查询**：需要 Chrome 105+，DSH 的 Electron 满足；仍保留 `@media` 兜底。
4. **旧测试**：断言旧 DOM 的用例会红，属于预期；用 `data-dsh-part` 作为稳定选择器，类名可以变。
5. **「在岗」不造假**：只用文件 mtime，文案写「记忆更新于」，不写「在线」。
6. **宽度**：设计稿是 1280 整页，落地后面板可能只有 700px；所有间距用相对值，断点先测 640 / 820 / 1180 三档。
